# Source and distribution scope

This repository contains authored tools, documentation and reconstructed C/C++,
including identified portions adapted from compatible public sources. It does
not distribute Ratchet & Clank: Size Matters,
disc images, executables, extracted assets, assembly dumps or Sony tools.
Contributors supply their own lawful game copy for local research.

The repository's authored material is licensed under GPL-3.0 (`LICENSE`).
Facts such as addresses, sizes, hashes and function boundaries may be recorded
without committing game bytes. Credit and preserve the licenses of any
third-party code before importing it.

Public, compatibly licensed GNU runtime code may be adapted with its original
copyright, license and exception notices intact. Cite an immutable public
upstream source and describe any modifications; a private SDK source path does
not establish provenance. Do not import Sony-specific SDK source, headers or
samples, even when a private compiler from that SDK is used to test a build.
Do not publish retail instruction listings in source comments or documentation.
