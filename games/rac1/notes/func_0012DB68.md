# func_0012DB68 (989snd.c, snd_StartSoundSystem)

Ported from the Lombyte draft with PAL addresses (US + 0x100). It needs:
- aliases `D_0015ECC0_b`/`D_0015ECE8_b` (struct), `D_00137C00_w`, and printf and func_0012E688 through aliases;
- `D_0015EDBC` as MACRO_ADDR. That means changing func_0012EC60's `*(int *)((char *)&D_0015EDBC + 0xC)` to `*(int *)&D_0015EDC8` and dropping the short declaration of D_0015EDBC, because the first declaration decides the `.extern` size.

What is left: the delay loops. Retail keeps 0x2710 in a saved register and computes `count - 1` at run time (`addiu v0,s18,-1`), then counts down to -1 with the counter written to the stack slot shared with the final command argument. Ours constant-folds to 0x270F. A `while (--arg != -1)` form and a count-up `for` both change size.
