# func_001F7680 (draw.c, chunked VRAM upload) — same size, ~40 words; not committed

Logic certain (build-sn/try/vu_best.c): per chunk of at most 0x80 blocks a
GIF packet (BITBLTBUF/TRXPOS/TRXREG/TRXDIR + IMAGE tag) and a DMA ref tag.
The chunk count is a 64-bit unsigned copy of the int remainder (`daddu`,
then `sltiu 0x81` + movz).

Residual: retail truncates each 64-bit shift of the count separately
(`dsll32 $x,c,3; dsra32` for vram, `c,11` for src, `(c<<7)` for the tag
words), where our build truncates the count once and shifts in 32 bits.
Explicit `(int)(c << k)` casts and plain compound assignments give the
same narrowed code. Register numbering differs as a result.
