# func_00208D38 (menu.c, map marker draw)

Right size, 166/616, from Lombyte's FUN_00208508 draft with PAL names.

Fixes to the draft:
- The deltas pair as `x = a0 + (a2 - a0) * res0` and `y = a1 + (a3 - a1) * res1`.
- The loop is `i = count; while (i-- != 0)`, which gives retail's `beq s3, -1`.
- `1 << n` uses a literal 1.

What is left: p/x/y rotate s0/s1/s2; the prologue computes the D_001A01F0 base in `$v1`; and the scale/table block is scheduled differently. Computing scale first made it worse (179).
