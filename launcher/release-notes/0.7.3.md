## The game

- **Vector maths that could go wrong in place.** The game's fast cross product (used for movement, aiming, collisions and effects everywhere) gave wrong results when it wrote its answer over one of its inputs. It now matches the original exactly. This was found by running the original game's code side by side with ours on real calls from play.

## For contributors

- 47 of the port's non-matched functions in the main program are now proven to behave exactly like the original on captured calls (rac1-decomp `tools/fcheck.py`).

The installers are built by the launcher workflow and are not signed. Your levels are not extracted again for this version.
