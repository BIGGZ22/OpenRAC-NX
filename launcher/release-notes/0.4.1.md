## The launcher

- **Play works again for everyone without a checkout.** 0.4.0 started the game in a folder that only a source checkout has, and Windows refused with "the directory name is invalid". Play now starts in the game's data folder, or in the installed copy's own folder when the usual one is missing.
- A test now plans Play the way the launcher does and starts the game that way, so this cannot slip past again.

The installers are built by the launcher workflow and are not signed for Windows or macOS.
