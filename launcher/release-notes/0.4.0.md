## The launcher

- **Install and play with just your disc.** The installer now carries the game and the tools it needs, including its own Python, so you no longer need git, Python or a compiler. Download the launcher, choose a folder, play.
- **A games folder.** On first start the Games page asks once for the folder your PlayStation 2 games are in. The launcher looks two folders deep and recognises discs by the boot program they name, whatever the file is called. Every game it can play is set up without more questions, up to the levels, so what is left is Play. A game whose disc is not in the folder still asks for a single image.

## The game

- **Escape pauses.** It used to end the program at once, losing your progress in the level. It now works as Start does; the window's close button ends the game.
- **A menu bar** with View, Sound and Developer entries: on macOS in the system menu bar (now named OpenRAC), on Windows and Linux along the top of the window (Alt shows and hides it).
- **F2** shows and hides the frame counter on every system.
- **Pause, step, slower, faster and screenshot** work without the debug panel. A line at the top says when the game is paused or slowed, and which keys undo it.

## For contributors

- Installers are built for Windows, Linux (Ubuntu 24.04) and Apple silicon, together with the carried copy of the tools. A checkout is still used first when one is found.
- The release job takes only this version's installers and both .rpm files.

The installers are built by the launcher workflow and are not signed for Windows or macOS.
