## Android

- **OpenRAC runs on Android.** The launcher and the game are one app for arm64 phones, tablets and handhelds (Android 10 and later): set the game up from your own disc image, as on a computer, and play with a controller or the on-screen pad.
  - An on-screen pad laid out like a DualShock 2, which puts itself away when a controller is used.
  - A drawer over the game, opened with Back, with the graphics settings and what the game draws with.
  - The game draws with OpenGL ES, or with Vulkan (experimental) where the phone has Vulkan 1.3, and can load another GPU driver.
  - The launcher updates itself from the releases. Every APK is now signed with one key, so updates install over each other; an APK from before this release has to be uninstalled once.

## The game

- **Crashes fixed.**
  - Umbris: the game could crash near the end of the level, where the sparks follow their path. Some of the game's local values were packed tighter than on the console, and a copy of a path point overwrote the counter beside it. Every planet gets the console's layout now.
  - US disc, Rilgar (Windows): a crash from a call that passed its arguments in the wrong order, which only Windows minds. Every such call in the port is now checked when it is built, and over fifty were fixed, on both discs.
  - US disc, Novalis: firing the Pyrocitor at the birds could crash the game. The weapon recorded the flame's length where the enemy expects the attacker.
  - A rare crash after a long session, from a texture size that cannot be right, and a slow growth in memory from text drawn over a long session.
- **The Pyrocitor.** Its firing sound stops when you let go of fire (US disc), and its pilot flame points along the nozzle again (European disc).
- **The bolt counter's comma** sits between the digits again: on most planets the counter's digits were spaced with another font's widths.
- **Menus and the Gadgetron vendor.** The pause pages' boxes no longer draw as noise, and the vendor's beam no longer turns black after its menu.
- **The game plays on in the background.** A controller still plays it while another window has the focus, and full screen on Windows no longer minimises when you click away. The keyboard still counts only while the game has the focus.
- **The flight between planets** draws the flight world's sky, and space only while the ship flies through it.
- **Vulkan on computers (experimental).** Windows, Linux and Mac games can draw with Vulkan: choose it in the launcher's Settings, under Advanced. Without Vulkan 1.3 the game draws with OpenGL as before. Macs use the MoltenVK each game carries, so nothing has to be installed.
- **Faster drawing** of the levels: fewer draws, terrain grouped by material and parts out of view culled.

## The launcher

- **Updates you are told about.** When an update changes the game, its page says so and offers **Rebuild now**, which builds it again from scratch; Play still starts the build you have. A game is only flagged when the update changed what it is built from.
- **Stable or development updates**, chosen in Settings, and the launcher says where its updates come from.
- **Disc images in .chd** can be set up as well as .iso.
- **Settings** are grouped, with the rarely changed folded away under Advanced, where the new renderer choice is.
- **Release notes** now come with every release, and the update prompt shows them.

## For contributors

- hostgen checks every call made through a code address against the function the game finds there (a test per game), and gives array and struct locals the console's stack slots.
- `OPENRAC_SOUND_LOG` also logs stops and still-playing checks.
- Building the port skips hostgen's translation when its inputs (the decompilation, the assembly and the disc) are unchanged.

The installers are built by the launcher workflow and are not signed for Windows or macOS. Your levels are not extracted again for this version.
