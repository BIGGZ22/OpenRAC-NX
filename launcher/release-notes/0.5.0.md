## The game

- **One game, one disc.** Ratchet & Clank is a single game in the launcher, with no region tabs to choose between. The US (NTSC-U) version builds from the same merged tree as the European one, using each version's own code where the two differ.
- **60 Hz for everything.** Every game runs at 60 Hz, and the European game draws in its own 60 Hz mode with its 448-line layout.
- **2D drawing fixes.** Each 2D list is drawn with the quads of the tick that built it, which stops pieces of the HUD and menus from lagging a frame.
- **Window icons** for each game.

## The launcher

- **Progress from the source.** The progress bars read straight from bytematch.dev for every game, with the share of functional C shown as a striped segment beside the matched share.
- **Update check.** The launcher looks for new releases on GitHub.
- **Discord** shows each game's own artwork.
- **The version switch** never blocks playing and no longer shows play steps.

## Where the port stands

- The European decompilation was synced with upstream's pull requests 76, 77 and 79 folded in, and the NTSC decomp with its latest matches.
- The US version now builds a large share of its functions from its own disassembly, with variants for the places where the versions differ, and checks whether one version's compiled code reproduces another's.

## For contributors

- games/rac1 is now the merged game, with the European tree as its base; tools can link a version's boot executable and level programs from another version's compiled functions.
- The README documents the level editor workflow, and RAC2's sources are translated with hostgen.

The installers are built by the launcher workflow and are not signed for Windows or macOS.
