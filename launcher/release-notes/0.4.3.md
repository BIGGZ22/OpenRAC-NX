## The launcher

- **Linux: older systems work.** The game is now built to need glibc 2.34 at most, so it starts on Ubuntu 22.04 and what is built on it (Linux Mint 21, Pop!_OS 22.04) and on Debian 12. It used to ask for glibc 2.38 and a newer C++ library.
- **You always play from the copy the launcher carries.** Players who had cloned OpenRAC, or had a checkout from an earlier launcher, were sent back to it, and playing there needs Python, compilers and a build. A checkout is now used only with Developer tools on, and switching them off goes back to the carried copy.

## Where the port stands

- The European decompilation was synced again: 4,360 of 5,109 functions (81.15% of the code) match.
- Two matches the port could not take as they were are now handled (one defined a function twice, one passed records by value where the PS2 passes addresses).

The installers are built by the launcher workflow and are not signed for Windows or macOS.
