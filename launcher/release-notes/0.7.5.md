## The game

- **Video options in the in-game pause menu.** Options during gameplay now includes a Video page with the same rows as the title menu (Resolution, Fullscreen, Aspect ratio, V-Sync, Frame limiter), applied live without returning to the title.
- **Taskbar icons on Linux.** Linux Wayland desktop environments (such as KDE Plasma) now show the game's icon in the taskbar and app switcher via desktop entry integration.
- **Renderer performance.** Auto-detects discrete GPUs on multi-GPU Linux systems and optimizes texture sampler usage in DirectRenderer.

## The launcher

- **Finds Godot on Windows.** The launcher now detects Godot 4 wherever players unpack or install it (Downloads, Desktop, Scoop, WinGet, Steam, itch, Chocolatey) and avoids probe timeouts.
- **No console popups on Windows.** Background operations and progress checks run silently without opening terminal windows.
- **Platform stability.** Sets cursor fallback under Wayland to prevent desktop crashes, and refines updater manifest keys for all installer types.

The installers are built by the launcher workflow and are not signed. Your levels are not extracted again for this version.
