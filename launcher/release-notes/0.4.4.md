## The launcher

- **Linux AppImage: the tools start again.** The AppImage exported a Python setting that made every tool crash at start with "No module named encodings". The launcher now clears it for itself and for everything it starts.

## The game

- **Fixes in the level code that run all 19 levels past 3,000 ticks.** The bomb glove's throw no longer collapses onto the hand on level 1; stray calls on levels 1, 11 and 13 are gone; a crash on a misaligned local on level 1 is fixed; and code now rounds toward zero as the console does, which stopped level 6 from trapping.

## For contributors

- `OPENRAC_GUARD` is a write watchpoint on game memory, and the trap report names its callers.
- hostgen handles variable-length arrays, keeps aligned typedefs, and lists the calls it fills with 0 because they were short of arguments.
- Both decompilations were synced again, and macOS builds no longer break on a Linux-only header.

The installers are built by the launcher workflow and are not signed for Windows or macOS.
