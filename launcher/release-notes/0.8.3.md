## The launcher

- **A simpler first run.** It asks one question, where your PS2 disc images are, and asks for the OpenRAC folder or Python beside it only when they were not found. Everything else it found folds under "Found for you". Start says why it is waiting.
- **The launcher stays out of your game.** A controller drove the launcher behind the game too, moving its focus and pressing its buttons. Now the controller only works the launcher while the launcher is in front.
- **Mods on Windows installs from 0.7.** An installed launcher upgraded from 0.7 saved its game folder under another spelling, so the Mods page looked in the wrong place. It now finds the folder under either name.
- **Progress shows again** for every game, after a game with no progress report yet broke the list.
- A pass over the launcher's layout, spacing and wording.
