## The game

- **The HUD shows up on every planet.** On Kerwan and other planets the HUD was drawn underneath the world and never seen; on Rilgar it flickered with the ocean. It now draws on top everywhere, on both discs.
- **Quit Game works.** After quitting from the pause menu, the controller stopped responding and the main menu came back with empty buttons. Both are fixed.
- **Fewer things going wrong in play.** A large pass over the code every level runs, checked against the original game:
  - calls that went to the wrong function in some levels' code (the likely cause of Batalia's crash),
  - values that could turn into "not a number" and send characters, particles or water off into nowhere,
  - menu and HUD text measured from the wrong place, a wrong menu string, a few wrong constants and limits,
  - missing pieces the game expected (64-bit maths helpers, system calls) now filled in.
- **Novalis** no longer logs an error every frame from a drawing callback.

### Still known on the US disc

- The Gadgetron popup is missing and the vendor screen is incomplete.
- Pokitaru's sky is flat cyan (on PAL too).

If Batalia still crashes for you, please tell us where: this release should fix it, but it hasn't been confirmed in play yet.

## For contributors

- `port/tools/hostgen/priority.py` ranks the functions gameplay goes through that still have no C or only approximate C, by how many levels reach them and whether they're on a hot path (`docs/workflow/BACKFILL.md`, "Picking what to backfill first").
- hostgen's report now includes its call graph and calls whose arguments disagree with the function they call.

The installers are built by the launcher workflow and are not signed. Your levels are not extracted again for this version.
