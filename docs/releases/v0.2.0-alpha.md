# OpenRAC-NX v0.2.0-alpha

Native Nintendo Switch port of Ratchet & Clank, based on OpenRAC. Requires your own **PAL Europe/Australia v2.00 ISO (SCES-50916 / SCES_509.16)**. No game data is included.

## Changes

- Native deko3d renderer for the game and launcher, including fixes for geometry, Gadgetron lettering, the Pyrocitor preview and fade edges.
- Redesigned launcher with custom artwork, menu colours, handheld/docked resolution profiles, gameplay controls and optional Status Monitor FPS/RES reporting.
- Revised frame-cap handling: a tick's picture is no longer declined as an extra between-frame after a slow update. The new pacing has passed host tests but has **not yet been verified on Switch**.
- Correct PAL game speed during boot, intro and title, following the game's own 50/60 Hz time base.
- Lower allocation overhead for animated characters through reused pose memory.
- Optional raised clock profile, **off by default**, with restore requests on HOME, sleep and exit. External clock managers can override requests; the latest lifecycle changes still need hardware verification.
- Diagnostic counter settings now turn off properly at `0`.
- Live game log moved to `SD:/switch/openrac/openrac-rac1-pal.log`.
- Selected upstream fixes, including the PAL Quartu-flight call and on-screen sprite edges.

## Install or update

Use **full application mode**. Performance varies by scene; an overclock is still needed for playable performance in demanding areas.

For a new installation, put the NRO and your supported ISO in `SD:/switch/openrac/`, allow at least 2 GiB extra space, and let Setup prepare the game. Keep the ISO after setup.

For an update, **back up saves and replace only the NRO**. Keep your ISO, prepared data and settings. Remove the previous NRO if you use the new versioned filename, so you launch the intended build.

## Known limitations

The latest pacing and clock-profile changes are not hardware verified. Cutscene animation/audio timing, performance consistency and a complete playthrough need further testing. Please report stutter with the log, build version and scene.

This download contains only the release NRO and its SHA256 checksum. No test configuration, diagnostic ELF or game data is attached.
